CalendarUnchecked.
Set up Calendar

In Orc, open Calendar and connect a Google account or an iCal address. This vault reads your next 24 hours from it.

GitHubUnchecked.
Set up GitHub

On the Mac running Orc, install the GitHub CLI and sign in.

brew install ghgh auth login

Check with gh auth status, then build the page again.

NotionUnchecked.
Set up Notion

Use the Claude login chosen in this vault’s Settings. Add Notion for that login.

claude mcp add --scope user --transport http notion https://mcp.notion.com/mcp

Open Claude Code, sign in to Notion with /mcp, then build the page again.

SlackUnchecked.
Set up Slack

Use the Claude login chosen in this vault’s Settings. Add Slack for that login. Your workspace admin may need to approve it first.

claude mcp add --scope user --transport http slack https://mcp.slack.com/mcp

Open Claude Code, sign in to Slack with /mcp, then build the page again.
